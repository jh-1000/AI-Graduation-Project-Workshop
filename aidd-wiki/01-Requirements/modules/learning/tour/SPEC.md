# SPEC — 导览与入口

## 能力清单
| ID | 能力 | 说明 |
|----|------|------|
| F-1 | 目标入口卡 | "整体怎么运行/AI 代码怎么看/怎么应对提问/怎么判断 AI 写对没"等 |
| F-2 | NL 路由 | 问题→知识点/流程/证据/练习；召回走轻量混合检索（SQLite FTS5 中文词法 + 图谱双链邻域 + 结构化过滤；P3 可选条目级语义索引）；候选制+推荐理由 |
| F-3 | 五站导览 | 认识项目→走通功能→关键机制→答辩拷问→独立修改验证 |
| F-4 | 冲刺模式 | 按答辩日期生成每日计划，可随时调整 |

## 业务规则
- R-1: 不得假设用户知道正确的技术术语。
- R-2: 学习顺序由任务书+项目重要性+前置依赖+实际表现共同决定。
