# SPEC — 知识库体系

## 能力清单
| ID | 能力 | 说明 |
|----|------|------|
| F-1 | 技术栈域组织 | 域来自项目真实栈（如 TS 语言机制/React/Express/SQL/工程工具），每域显示知识点数与掌握进度 |
| F-2 | 双视图 | 按技术域 / 按五类学习对象（业务功能/执行机制/核心概念/设计决策/验证与异常）切换 |
| F-3 | 条目沉淀 | 每条含十段讲解、寓言卡、掌握状态、下次复习时间、前置依赖、所属流程、项目用法锚点 |
| F-4 | 术语表 | 术语独立浏览（GLOSSARY 纪律：通俗/专业/示例/误区/Avoid 别名/项目用法） |
| F-5 | 复习队列 | FSRS 调度：今日到期卡（问题→翻面→记得/忘了→下次间隔）；掌握判定与调度分离 |
| F-6 | 学习历史 | learning-records 可查（何时学会、依据什么证据） |

## 业务规则
- R-1: 知识库内容全部来自本项目分析产物与学习记录，不放通用教程。
- R-2: 项目变更使知识点过期时，条目显示"需重验"而非静默保留旧状态。
