# SPEC — 练习与掌握度

## 能力清单
| ID | 能力 | 说明 |
|----|------|------|
| F-1 | 六级练习 | 选解释/自己解释/找代码/补调用链/解释错误与理由/修改并验证 |
| F-2 | 阶梯提示 | 小提示→具体提示→最后才给答案+代码证据 |
| F-3 | 能力雷达 | 概念解释/代码定位/流程追踪/设计理由与边界/修改与验证/AI 协作与判断 |
| F-4 | FSRS 复习 | ts-fsrs D/S/R 调度；迁移检查用不同问法 |
| F-5 | 学习记录 | 四触发写入；mere coverage 不写；superseded 不删 |

## 业务规则
- R-1: 掌握判定与复习调度分离。
- R-2: 不采个人信息、不打固定能力标签。
