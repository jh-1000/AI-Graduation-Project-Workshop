# REQ — 代码库阅读器

## 用户故事
- US-1: 作为用户，导入完整项目后，我想像 IDE 一样浏览代码库：文件树、语法高亮、行号、符号大纲——不用切换工具。
- US-2: 作为用户，我在证据卡/流程线/图谱里看到 file:line 时，想一键跳进阅读器并定位到那一行。
- US-3: 作为用户，答辩被问"这段代码谁在调用"时，我想选中符号立刻看到调用者/被调用者并跳转。

## 验收标准
- AC-1: 文件树 + 高亮阅读 + 行号定位可用；完全只读，无任何编辑入口。
- AC-2: 证据行在 gutter 有琥珀标记，点击查看证据卡；证据卡可反向跳入阅读器定位行。
- AC-3: 符号大纲（来自 symbols 表）点击跳行；选中符号显示调用者/被调用者（来自整库引用图）并可跳转。
