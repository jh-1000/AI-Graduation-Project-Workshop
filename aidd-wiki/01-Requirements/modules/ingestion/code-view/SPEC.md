# SPEC — 代码库阅读器

## 能力清单
| ID | 能力 | 说明 |
|----|------|------|
| F-1 | 文件树 | 目录折叠、当前文件高亮，数据来自 files 表 |
| F-2 | 代码阅读 | 语法高亮（Shiki 正式版）+ 行号 + 长文件虚拟滚动（P2） |
| F-3 | 证据层 | 证据行琥珀标记 + gutter 图标 + 点击看证据卡；证据卡反向跳入定位 |
| F-4 | 符号大纲 | 当前文件函数/类/路由（symbols 表），点击跳行 |
| F-5 | 调用关系 | 选中符号 → 调用者/被调用者（整库引用图），点击跳转 |
| F-6 | 只读边界 | 无编辑入口；修改仅存在于挑战隔离区（Auth-L5） |

## 业务规则
- R-1: 阅读器是"看"的终点、"改"的起点——所有证据跳转都汇聚到这里。
- R-2: 大仓库性能走虚拟滚动 + 按需加载（P2 实现细节）。
