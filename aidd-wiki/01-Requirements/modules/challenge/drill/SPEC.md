# SPEC — 定位与改码挑战

## 能力清单
| ID | 能力 | 说明 |
|----|------|------|
| F-1 | 定位题 | 文件树点选，整库引用图核验（路径+行号容差） |
| F-2 | 改码题 | 隔离 worktree（非 git 用副本+备份）；diff 展示；验证命令 |
| F-3 | 破坏实验 | 删/改一处→运行观察→解释→一键还原 |
| F-4 | 验证闭环六查 | 定位正确/满足需求/副作用/测试可跑则跑（不可跑显示"未验证"）/能解释原因/先定位再动手 |
| F-5 | AI 协作 playbook | 改码任务配双重学习模板 |

## 业务规则
- R-1: worktree 不是沙箱；命令须独立副作用审查。
- R-2: 过关判定用完成审计——"审计必须证明完成，而不只是没发现明显未完成"。
